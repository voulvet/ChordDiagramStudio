Files with the same group are combined into one diagram (e.g. two studies); different groups are compared (e.g. Control and OA, or two time-points). The file label names each file in the diagram (e.g. Study A).

Regions

Found from the code in brackets at the end of a variable name, e.g. "(MED)", or after the last separator, e.g. "_MED".

Categories

Untick to exclude. Arrows set the order around the ring. Colours stay fixed per category. Label = short name inside the ring; Group = outer ring (e.g. tissue). Both are read from a "Categories" sheet when the file has one.
