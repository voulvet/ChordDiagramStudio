**New in 2.0.0**

- **Several Excel files.** Give each file a group and a file label: files of the same group are combined (e.g. two studies; correlations are never computed across files), different groups are compared. Three layouts: *compare groups* (categories left, groups right, optional highlight), *one full circle per group*, and *one diagram per group with the files (and regions) on the right*. Regions with the same code in different files can be kept separate or combined.
- **Balanced left side** in the comparison: every category that takes part in a correlation appears on the left.
- **Highlight** one group in the comparison; the other groups are toned down.
- **Same chord thickness across a run**, or a fixed width in degrees.
- **Larger category labels** (size and characters per line), with leader lines that stay outside the ring and never cross.
- **Count scale** on the rings, and segments proportional to the number of chords.
- **Extra rings**: category group (from a new `Categories` sheet: Category, Label, Group), region and file, with names curved inside the rings or placed outside with leader lines. Ring colours are chosen so they cannot be confused with the category colours.
- **Changes between two groups** workbook: correlations that appeared, disappeared or changed sign, sorted by strength, with one sheet per region and a built-in count check.
- **Checks on the input files**: damaged sheet names are repaired, non-breaking and repeated spaces are normalised, names that differ only in spaces/underscores are matched and listed, and possible typos are reported.
- New synthetic example files (two studies × two groups, with Variables and Categories sheets).

Every option works the same on the website, in the desktop program and on the command line (see README).

Downloads: Mac (Apple chip, Intel), Windows, Linux (x86-64, ARM64). On a Mac, run `xattr -cr` on the unzipped folder first (see README.txt).
