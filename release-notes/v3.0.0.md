**New in 3.0.0**

- **Strength categories as tick boxes.** Tick which strength categories to draw: very strong (|r| ≥ 0.80), strong (0.60–0.80), moderate (0.40–0.60), weak (< 0.40). The cut-offs are fixed. The diagram, counts and tables contain only the ticked categories, and the title says which are shown (e.g. "strong and very strong correlations, |r| ≥ 0.60"). Command line: `-strength "very strong,strong"`.
- **Simpler settings.** Titles and file names are now always automatic. Removed: combine categories, keep apart, one diagram per category, own title, own file-name prefix, and reading the Categories sheet from a separate file (the Categories sheet in the data file still works).
- Command line: `-out` is now the output folder; removed flags `-merge`, `-apart`, `-series`, `-title`, `-categories`.

Every option works the same on the website, in the desktop program and on the command line (see README).

Downloads: Mac (Apple chip, Intel), Windows, Linux (x86-64, ARM64). On a Mac, run `xattr -cr` on the unzipped folder first (see README.txt).
